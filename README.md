# مساعد الاجتماعات | Meeting Assistant

مساعد ذكي تتكلم معاه كتابة وصوت (بحث، شرح، تدريب لغة) بكرة أو شخصية متحركة، ترجمة فورية، محادثات بدون توقف، تفريغ وتلخيص الاجتماعات، إيميلات بأسلوبك، ومهام بتذكيرات.
يعمل في المتصفح على الموبايل والتابلت والكمبيوتر، بدون اشتراك أو مفتاح API.

**افتح التطبيق:** https://engaasal-code.github.io/meeting-assistant/

- بيانات كل مستخدم مشفّرة ومحفوظة على جهازه فقط.
- نسيت كلمة المرور؟ يوصل رابط تأكيد على الإيميل وتختار كلمة جديدة.
- على آيفون: افتح الرابط في Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية.
- على أندرويد: Chrome ← القائمة ← إضافة إلى الشاشة الرئيسية.
